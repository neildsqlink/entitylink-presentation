# EntityLink — מצגת כנס יועצים משפטיים

מצגת React + Vite עם אנימציות (8 שקפים · ~6 דקות).

## הרצה

```bash
npm install
npm run dev
```

ואז לפתוח את הכתובת שמודפסת (ברירת מחדל: http://localhost:5173).

## שליטה

- **קליק / חץ שמאלה / רווח** — שקף הבא
- **חץ ימינה** — שקף קודם
- **F** — מסך מלא
- **Home / End** — התחלה / סוף

## מבנה

- `presentation.jsx` — כל השקפים והאנימציות
- `public/screenshots/` — צילומי מסך מהמערכת
- `legacy.html` — הגרסה הישנה (HTML סטטי, נוחה להדפסת PDF)
- `EntityLink-מצגת-תסריט.md` — תסריט הדיבור

## build לקובץ סטטי

```bash
npm run build
```

הפלט נכתב ל-`dist/` ואפשר להעלות לכל אחסון סטטי.
